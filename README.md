# Historial Académico - Centro de Educación Alternativa (CEA)

Sistema de gestión de historial académico desarrollado con Flask-AppBuilder, Python y MySQL.

## Temática
Digitalizar el historial académico de participantes del CEA, facilitando a facilitadores el registro de calificaciones y a gestores la consulta de reportes.

## Tecnologías
- Python
- Flask-AppBuilder
- MySQL
- Git/GitHub
